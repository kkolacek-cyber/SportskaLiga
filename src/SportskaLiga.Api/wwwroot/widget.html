NK Primjer – službena stranica

Ovo je izmišljena stranica kluba koja prikazuje podatke lige pomoću widgeta (JavaScript + Web API).


Kako ugraditi

Klub na svoju stranicu doda element i skriptu:

<div data-liga-widget="tablica"></div>
<div data-liga-widget="rezultati" data-momcad="3"></div>
<script src="http://localhost:8083/liga-widget.js"></script>

Atributi: data-sezona (Id sezone, zadano aktivna), data-momcad (samo utakmice momčadi), data-broj (broj utakmica).
